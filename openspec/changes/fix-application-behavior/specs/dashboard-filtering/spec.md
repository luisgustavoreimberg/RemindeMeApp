## ADDED Requirements

### Requirement: Dashboard Filtering
The dashboard SHALL allow users to filter tasks/tags by Name, Elapsed Time, and Completion Date.

#### Scenario: Filtering tasks by name
- **WHEN** the user applies a name filter
- **THEN** the dashboard displays only tasks/tags matching the filter criteria

### Requirement: Dashboard Sorting
The dashboard SHALL allow users to sort tasks/tags alphabetically, by completion date, or by elapsed time.

#### Scenario: Sorting tasks alphabetically
- **WHEN** the user selects alphabetical sorting
- **THEN** the dashboard reorders the tasks/tags from A to Z or Z to A based on selection

### Requirement: Quick Task Date and Tag Selection
The Quick Task creation input SHALL allow users to click the date and tag icons to open selection popups.

#### Scenario: Clicking Quick Task icons
- **WHEN** the user clicks the date or tag icon in the Quick Task input
- **THEN** the corresponding selection popup opens
